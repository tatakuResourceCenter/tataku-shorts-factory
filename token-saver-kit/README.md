# 🪙 토큰 아끼는 키트 (DAY 3)

클로드 쓰다가 **"사용량 한도에 도달했습니다"** 때문에 작업이 끊긴 적 있죠?
로블록스 드라마를 만들며 매일 부딪혀서 찾은 **토큰 절약 규칙**을 스킬과 프롬프트로 만들었어요.
품질은 그대로, 줄이는 건 말·반복·불필요한 확인뿐이에요.

## 📥 다운로드
👉 **[키트 한 번에 받기 (zip)](https://github.com/tatakuResourceCenter/tataku-shorts-factory/raw/main/token-saver-kit/토큰절약_키트.zip)**

## ⚡ 방법 1 — 붙여넣기 (제일 쉬움, 웹 채팅 OK)
[`PASTE_PROMPT_토큰절약.txt`](PASTE_PROMPT_토큰절약.txt) 내용을 **새 채팅 첫 메시지로** 붙여넣기 → "토큰 절약 모드 켰어요!" 하면 끝.

## 🧩 방법 2 — 스킬 설치 (매번 자동 적용)
[`token-saver.zip`](https://github.com/tatakuResourceCenter/tataku-shorts-factory/raw/main/token-saver-kit/token-saver.zip) 을 Claude **설정 → 기능(Capabilities) → 스킬 → 업로드** (Claude Code는 `~/.claude/skills/` 에 폴더째 복사)

## 📏 들어 있는 규칙
| # | 규칙 | 왜 |
|---|---|---|
| 1 | 결론 먼저, 짧게 | 긴 요약·반복이 제일 흔한 낭비 |
| 2 | 긴 코드는 처음 한 번만, 그다음엔 바뀐 줄만 | 20KB 코드를 매번 다시 붙이면 금방 바닥 |
| 3 | 스크린샷보다 글자 로그 먼저 | 이미지는 토큰을 많이 써요 |
| 4 | 영상은 프레임 하나씩 말고 모아보기 한 장 | 60장 → 1장 |
| 5 | 재생 확인은 내가 직접 (F5) | 사람이 보면 토큰 0 |
| 6 | 한 번에 계획하고 한 번에 실행 | 왔다 갔다 줄이기 |
| 7 | 잘 된 건 저장해서 재사용 | 매번 새로 만들기가 최대 낭비 |
| 8 | 길어지면 인수인계 → 새 채팅 | 긴 대화는 매번 앞 내용을 다시 읽어요 |
