# 쇼츠 편집 공식

반려동물 쇼츠 채널에서 통하는 패턴. 실제 작업하며 정리한 것.

## 원본 영상 뜯어보기

편집을 시작하기 전에 **어디서 움직임이 터지는지**부터 찾는다.
프레임 차이를 재면 눈으로 보지 않아도 박자가 나온다.

```python
raw = subprocess.run(['ffmpeg','-v','quiet','-i',V,'-vf',
      'fps=10,scale=90:160,format=gray','-f','rawvideo','-'],
      capture_output=True).stdout
fr = np.frombuffer(raw, dtype=np.uint8).reshape(-1,160,90).astype(np.float32)
motion = np.abs(np.diff(fr, axis=0)).mean(axis=(1,2))
```

값이 치솟는 지점이 "사건"이고, 평평한 구간은 **잘라내거나 빨리 감을 후보**다.

실제 사례: 21.7초 원본에서 6.4~12.4초가 거의 정지 상태였다.
2.5배속으로 압축해 16.5초로 줄였더니 훨씬 잘 붙었다.

## 길이

채널 평균이 11초였다. 쇼츠는 짧을수록 끝까지 보는 비율이 올라간다.
**정지 구간은 과감히 압축하고 16초 안쪽을 목표로 한다.**

## 구조

| 구간 | 할 일 |
|---|---|
| 0~2초 | 상황을 한 줄로 던진다. 궁금하게 만든다 |
| 중반 | 사건 → 반응. 정지 구간은 압축하거나 "정색" 개그로 쓴다 |
| 후반 | 반전 또는 해소 |
| 마지막 1.5초 | 프리즈 프레임 + 구독 유도 |

정지 구간을 무조건 버릴 필요는 없다. 고양이가 가만히 노려보는 장면은
`(정색)` 자막 한 줄만 얹으면 그 자체로 웃음 포인트가 된다.

## 제목

두 줄로 나누고 윗줄은 노란색, 아랫줄은 검정. 끝에 `ㅋ` 또는 `ㅋㅋ`.

```
집사 손 한번 잡더니        ← 노랑, 검정 테두리
절대 안 놔주는 고양이ㅋㅋ    ← 검정
```

상단에 흰 띠를 깔고 그 위에 올린다. 720×1280 기준 높이 186px.

## 자막

- 화면 아래에서 300px 위, 가운데 정렬
- 노란색(`#FFF02A`) + 검정 테두리 7px
- 한 덩어리 18자 이내
- 상태는 괄호로: `(꾹)` `(정색)` `(집사 백기)`

## 내레이션

**내레이터와 캐릭터를 다른 목소리로 나눈다.** 대비가 생겨야 웃기다.

- 내레이터: 밝고 빠른 톤, 상황 설명
- 캐릭터: 낮고 시큰둥한 톤, 짧게 툭툭

대사는 짧을수록 좋다. 한 줄 15자를 넘기면 슬롯에 안 들어간다.

## ffmpeg 조각

### 구간을 이어 붙이며 중간만 빨리 감기

```bash
ffmpeg -ss 0 -to 6.4 -i in.mp4 -an -c:v libx264 -crf 18 A.mp4
ffmpeg -ss 6.4 -to 12.4 -i in.mp4 -an -filter:v "setpts=0.4*PTS" -c:v libx264 -crf 18 B.mp4
ffmpeg -ss 12.4 -to 18.2 -i in.mp4 -an -c:v libx264 -crf 18 C.mp4
ffmpeg -f concat -safe 0 -i list.txt -c copy out.mp4
```

### 마지막 프레임 얼리기

```bash
ffmpeg -ss 18.0 -i in.mp4 -frames:v 1 last.png
ffmpeg -loop 1 -t 1.8 -i last.png -c:v libx264 -pix_fmt yuv420p -vf scale=720:1280 D.mp4
```

### 음성을 지정 초에 배치

```bash
ffmpeg -i video.mp4 -i v1.wav -i v2.wav \
  -filter_complex "[1:a]adelay=200|200[a1];[2:a]adelay=3200|3200[a2];\
                   [a1][a2]amix=inputs=2:normalize=0,alimiter=limit=0.95,apad,atrim=0:16.47[out]" \
  -map 0:v -map "[out]" -c:v copy -c:a aac out.mp4
```

`-shortest` 를 쓰면 **영상 끝이 잘린다.** 음성이 영상보다 짧으면
`apad` 로 무음을 채우고 `atrim` 으로 영상 길이에 맞춘다.

## 검증

합성한 뒤 눈과 귀로만 확인하지 말고 숫자로 확인한다.

```python
def rms(a, t0, t1, sr=8000):
    s = a[int(t0*sr):int(t1*sr)]
    return float(np.sqrt((s**2).mean()))

# 각 대사 구간에 소리가 있고, 직전 0.3초는 조용한지
inside = rms(a, start, start + dur)
before = rms(a, start - 0.3, start)
assert inside > 0.01 and inside > before * 2
```

  안 그러면 저작권 신고나 "재사용된 콘텐츠" 사유로 수익화가 막힌다
