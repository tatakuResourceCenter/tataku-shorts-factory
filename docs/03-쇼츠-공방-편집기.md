# 쇼츠 공방 편집기 v2

`editor/편집기.bat` 을 더블클릭하면 브라우저에 편집기가 열린다 (http://127.0.0.1:8765).
검은 창을 닫으면 편집기도 꺼진다. 코드를 바꿨으면 검은 창을 닫고 다시 실행한다.

## 폴더

2026-11-20 부터 랭킹 작업은 `랭킹/`, 예능 작업은 `예능/` 안에 따로 저장된다 (`예능/편집.json`, `예능/원본/`, `예능/대본.json`, `예능/output/`).

| 위치 | 내용 |
|---|---|
| `clips/` | 쇼츠에 쓸 원본 클립 |
| `refs/` | 참고 예시 사진 (쇼츠 구성 미리보기에 겹쳐 보기) |
| `voice/` | 줄마다 만든 음성 (`<줄id>.wav`) |
| `output/` | `구성영상.mp4`, `완성본.mp4`, `썸네일_*.png` |
| `분석/` | Claude 가 대본 쓸 때 만든 장면 시트 |
| `보관함/날짜_제목/` | 새 쇼츠 시작하기로 옮겨 둔 지난 작업 |

## 파일 형식

### 구성.json
```json
{"title1":"심장폭행하는 고양이들","title2":"랭킹 TOP5","sub":"(뭐가 제일 심장폭행이야?)",
 "bandHeight":460,"order":"5to1","numColors":["#FF3B3B","#FF9F1C","#FFE14D","#687bb6","#41cd0e"],
 "keepAudio":true,"voiceEmo":{"narr":"happy","cat":"toneup"},"brief":"",
 "clips":[{"rank":1,"file":"….mp4","label":"내꺼야 내꺼라고","start":0,"end":10.5,"source":"@bambi_22918"}]}
```

### 대본.json
```json
[{"speaker":"cat","clip":5,"at":5.0,"slot":1.6,"text":"멍멍아 놀자옹!",
  "emotion":"toneup","intensity":1.2,"speed":1.1,"pitch":1}]
```
`clip` 은 랭크, `at` 은 그 클립 안의 초. 완성 영상 시각은 서버가 계산한다.
음성을 만들면 `duration`, `file`, `fit`, `key` 가 붙는다.

### 업로드정보.json
`titles`(3), `thumbs`(file · title · idea · frame), `intro`, `hashtags`, `tags`, `pinned`.
설명란은 intro + 출처 목록(자동) + hashtags 로 합쳐진다.

## 서버 API (요약)

- `GET /api/state` — 화면에 필요한 모든 것 (버전, 수첩, 구성, 대본, 클립 시간표, 결과 파일, 업로드 정보)
- `POST /api/generate {index}` — 한 줄 음성 (바뀐 게 없으면 건너뜀)
- `POST /api/finish` — 음성 → 구성 영상 → 더빙 합성
- `POST /api/pick-video` — 윈도우 열기 창으로 영상 고르기
- `POST /api/sources/{add,update,attach,attach-clear,delete}` — 클립 수첩
- `POST /api/refs/{upload,delete}` — 참고 예시 사진
- `POST /api/reset` — 보관함으로 옮기고 새로 시작
