# 쇼츠 음성 입히기

영상의 특정 순간에 대사가 **정확히 떨어지도록** 타입캐스트 음성을 만든다.

## 언제 쓰나

- 쇼츠·릴스에 내레이션이나 캐릭터 더빙을 얹을 때
- "이 장면에서 이 대사가 나와야 한다"는 타이밍 제약이 있을 때
- 대사를 고쳐가며 여러 번 다시 뽑아야 할 때

## 핵심 원칙

**음성에 영상을 맞추는 게 아니라, 음성을 슬롯에 맞춘다.**
단 억지로 맞추지 않는다. `audio_tempo` 는 0.88~1.22 안에서만 움직이고
그 밖으로 나가야 할 상황이면 대사를 줄이라고 알린다.

## 순서

### 1. 원본에서 박자 찾기

프레임 차이로 움직임이 터지는 지점을 찾는다. 그 지점이 대사의 앵커가 된다.
정지 구간은 압축하거나 "정색" 개그로 쓴다.

### 2. 대본 짜기

줄마다 이렇게 정한다.

```python
(id, 화자, 시작초, 허용길이, [감정 선호순], 강도, 텍스트)
(3, "cat", 4.70, 0.60, ["toneup", "happy"], 1.0, "어?")
```

- 감정은 **하나로 못 박지 말고 선호 순서로** 적는다 (목소리마다 지원이 다름)
- 한 줄 15자를 넘기면 슬롯에 안 들어갈 가능성이 높다
- 슬롯은 예상보다 20~30% 넉넉하게

### 3. 목소리 고르고 지원 감정 확인

```python
v = client.voice_v3(voice_id)
supported = {m.emotions for m in v.models if m.version.value == "ssfm-v30"}
```

선호 목록에서 지원하는 첫 감정을 고른다. 없으면 `normal` 로 떨어뜨린다.

### 4. 생성과 보정

```python
res = client.text_to_speech_with_timestamps(req, granularity="word")
dur = res.audio_duration
if dur > slot + 0.06:
    tempo = min(1.22, tempo * (dur / slot))   # 재생성
```

`remove_silence_ms=0` 으로 앞뒤 무음을 잘라야 시작점이 정확해진다.

### 5. 합성과 검증

`adelay` 로 각 음성을 지정 초에 배치한다. `-shortest` 는 쓰지 않는다
(영상 끝이 잘린다). `apad` + `atrim` 으로 영상 길이에 맞춘다.

합성 후 구간별 RMS 를 재서 대사가 제자리에 있고 직전이 조용한지 확인한다.

## 자주 걸리는 것

- **감정이 목소리마다 다르다.** 전체 20종 중 7종만 되는 목소리가 흔하다
- **웹 구독 ≠ API 플랜.** 403 이 뜨면 이것부터 의심
- **TTS 는 생각보다 빠르다.** 한국어 5.6자/초로 잡으면 대체로 여유 있게 들어간다
